Overview

About this service

Backend & Automation is where I build the quiet, dependable services that everything else in your product leans on.

Most of the systems I ship here run 24/7, talk to flaky third-party APIs, and absolutely cannot drop messages.

I write services in FastAPI, Node.js and Python with explicit timeouts, retries with backoff, and circuit breakers around every external call.

Async work goes through Celery or queue-backed workers, with idempotent handlers so retries never double-charge, double-trade or double-send.

For automation surfaces, I build Telegram and Slack command bots with role-based access, audit logs, and human-in-the-loop confirmation for dangerous actions.

Every endpoint emits structured JSON logs and traces so when something does break at 3am, the post-mortem takes minutes, not hours.

I treat rate limits and exchange quirks as first-class concerns — token buckets, jittered retries, and graceful degradation are built in, not bolted on.

Auth is done properly: scoped API keys, short-lived JWTs, and per-tenant isolation where it matters.

I've designed kill-switches for automated trading systems that halt all activity from a Telegram command in under one second.

Uptime on my production deployments sits at 99.95%+ over rolling 90-day windows, with P95 latency under 200ms end-to-end.

I document every endpoint with OpenAPI and ship a Postman or Bruno collection so your team can integrate without guessing.

If your backend is the 'scary part of the codebase no one wants to touch', this engagement turns it into a system you trust.
